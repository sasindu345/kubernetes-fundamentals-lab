# kubernetes-fundamentals-lab

Repository scaffold for Kubernetes fundamentals practice.

## Structure

- `app/frontend/` - frontend application
- `app/backend/` - backend application
- `docker/` - Docker-related files
- `k8s/` - Kubernetes manifests organized by topic
- `scripts/` - helper scripts
- `docs/` - project documentation
- `images/` - diagrams and reference images
